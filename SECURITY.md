# Security and Disclosure

This repository is illustrative portfolio code, not a deployable production service. All orders, customer IDs and identities are fictional.

- Never commit production credentials, client contact data, or internal infrastructure addresses.
- Never publish a customer's actual source repository or Git history after merely renaming identifiers.
- Tool permissions are checked by backend code, independent of model instructions.
- A production deployment requires durable database-backed event claims, authentication, rate limiting, monitoring, and a human-approval mechanism.
- This sample is not connected to any real CRM, payment, messaging or client system.
